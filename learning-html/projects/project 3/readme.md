<h2> 🎓 Final HTML Capstone Project: Registration & Survey Form </h2>

This is the final challenge of Phase 1 (HTML)! Once you pass this, you will have officially mastered HTML structures and we will move on to Phase 2 (CSS) to make your pages look beautiful.


<b>Your Task:</b><br>
1. Inside your `project 2` folder, create a new file named `survey.html`.
2. Set up the standard boilerplate and update the navigation on <b>all four of your other pages</b> to include a link to `survey.html` (and add navigation to `survey.html` as well).
3. In the `<main>` section of `survey.html`, create a detailed Survey Form.
4. Your form <b>must</b> contain:
    * <b>Full Name:</b> A text input.
    * <b>Email:</b> An email input.
    * <b>Password:</b> A password input.
    * <b>Role/Experience:</b> A dropdown (`<select>`) with options like "Student", "Developer", "Hobbyist".
    * <b>Preferred Learning Track (Checkboxes):</b> At least 3 checkbox options (e.g. IoT, AI/ML, Robotics) where the user can select multiple.
    * <b>Coding Experience Level (Radio Buttons):</b> At least 3 radio buttons (e.g., Beginner, Intermediate, Expert). Remember to give them the same `name` so only one can be selected!
    * <b>Additional Comments:</b> A `<textarea>` box.
    * <b>A Submit Button</b> (`<button type="submit">`).
    * Proper `<label>` tags with matching `for` and `id` for every single input control.<br><br>

Write the code in `survey.html`, test it in your browser to make sure the checkboxes let you click multiple, the radio buttons only let you select one, and all labels work.
