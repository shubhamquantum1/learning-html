### 🍳 Mini-Project 1: Text-Only Recipe Page

<b><u>Your Task:</b></u>
1. In your workspace folder, create a new file named `recipe.html`.
2. Write a recipe page for any dish you like (e.g., how to make tea, a sandwich, or instant noodles).
3. The page must contain:
4. The standard HTML boilerplate structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, etc.).
5. A page title in the `<title>` tag.
6. A main heading (`<h1>`) for the name of the recipe.
7. A short paragraph (`<p>`) describing the dish. This paragraph must contain at least one bold (`<strong>`) word and one italic (`<em>`) word.
8. An Ingredients section with an `<h2>` heading and an unordered list (`<ul>`) listing at least 3 ingredients.
9. An Instructions section with an `<h2>` heading and an ordered list (`<ol>`) listing at least 3 steps in order.
10. At least one line break (`<br>`) somewhere on the page.

Write the code in `recipe.html`, save it, and view it in your browser.
